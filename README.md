# 📊 AdventureWorks Sales Analysis Dashboard – Tableau

An interactive **AdventureWorks Sales Analysis Dashboard created using Tableau** to analyze sales performance, customer trends, product performance, and business insights through dynamic visualizations.

## 🔍 Project Overview

This project uses the **AdventureWorks dataset** to create an interactive Tableau dashboard for analyzing sales data and identifying important business trends and performance indicators.

## 🛠️ Tools & Technologies

* **Tableau**
* **AdventureWorks Dataset**
* **Data Visualization**
* **Data Analysis**
* **Calculated Fields**
* **Interactive Filters & Parameters**

## 📈 Key Features

* Interactive sales analysis dashboard
* Sales and profit performance analysis
* Product and category analysis
* Customer and regional performance analysis
* Sales trend analysis
* Interactive filters and visualizations
* KPI-based business performance analysis
* Dynamic charts for better data exploration

## 🎯 Objective

The objective of this project is to transform AdventureWorks sales data into an **interactive and visually engaging Tableau dashboard** that provides useful insights into sales performance and supports data-driven decision-making.

## 📁 File

`Adventure Work Sales Analysis Dashboard - Tableau.twbx` – Tableau packaged workbook containing the dashboard, visualizations, data, and workbook configuration.
